# Ações do 2º turno

Plataforma onde quem organiza ações para eleger o Lula no 2º turno (panfletagem, adesivaço, roda de
conversa, ligatona...) cadastra a ação, e quem quer ajudar acha uma perto de si e se inscreve.
Desenho em `docs/superpowers/specs/2026-10-08-plataforma-acoes-design.md`.

Estado: **mockup navegável** em `mockup/index.html` (abrir no navegador; publicado como artifact privado em https://claude.ai/artifact/5FLiCyZHCJD6ADZbofmrjL). Capturas em `docs/capturas/`. Desenho visual em `docs/2026-10-08-design-mockup.md`. A busca por lugar usa `mockup/lugares.js` (municípios do IBGE via kelvins/municipios-brasileiros, MIT, e os 96 distritos da capital). Dados de exemplo em
`mockup/dados.js`. Testes: `python -m pytest tests`.
